# Track Map

## Anchor

### Venice — Private Agents, Trusted Actions

- The product thesis maps directly to this track.
- Private evaluation is not garnish. It is the decision layer for sensitive agent procurement.
- Current live prize pool: `11500 USD equivalent`.

## Primary

### MetaMask — Best Use of Delegations

- Delegated, permission-bounded execution is the core authorization mechanism.
- This should become a real product primitive, not a simulated approval button.
- Current live prize pool: `5000 USD`.

### Uniswap — Agentic Finance

- Settlement is load-bearing.
- If funds need to be routed or swapped before payment, Uniswap becomes part of the real workflow.
- Current live prize pool: `5000 USD`.

### OpenServ — Ship Something Real

- GhostBroker is naturally a multi-agent product.
- The broker agent coordinates specialist agents and can evolve into a paid service.
- Current live prize pool: `4500 USD`.

### Base — Agent Services on Base

- The product itself is a discoverable paid agent service.
- The market-facing version can expose the broker as a service to humans and other agents.
- Current live prize pool: `5000 USD`.

## Strong

### Protocol Labs — Agents With Receipts

- Durable receipts and ERC-8004-linked execution history can become a real trust primitive.
- This gets stronger if receipts are persistent, queryable, and reusable as reputation.
- Current live prize pool: `4000 USD`.

### Protocol Labs — Let the Agent Cook

- This becomes viable if GhostBroker is truly autonomous end-to-end, not just a UI shell.
- Current live prize pool: `4000 USD`.

### Self — Best Self Agent ID Integration

- Human-backed identity should gate trust, provider onboarding, or reputation.
- The win condition here is load-bearing identity, not decorative verification.
- Current live prize pool: `1000 USD`.

## Qualifier

### Filecoin Foundation — Best Use Case with Agentic Storage

- Receipts, state, and reputation can be anchored to persistent storage.
- This should fall out naturally from the receipts system rather than become a side quest.
- Current live prize pool: `2000 USD`.

### ENS — ENS Identity

- Agent names and human-readable identity improve discovery and credibility.
- This is low-effort if the naming layer is cleanly integrated.
- Current live prize pool: `600 USD`.
